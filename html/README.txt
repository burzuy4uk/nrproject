ЩО ВСЕРЕДИНІ
- assets/header/header.css — градієнтний UA-хедер, приховано підзаголовок.
- css/theme-ukraine.css — фіолетові акценти + чипи/пагінація у новинах.
- js/active-nav.js — автопідсвічування активного пункту меню.
- index.html + 7 сторінок (про фонд/партнери/засновники/історія/документи/керівництво/структура).

ЯК ЗАСТОСУВАТИ
1) Скопіюй усі файли поверх проєкту, підтвердь заміну header.css.
2) Переконайся, що після /css/style.css підключено /css/theme-ukraine.css.
3) Додай <script src="/js/active-nav.js" defer></script> перед </body> (у головному layout).
